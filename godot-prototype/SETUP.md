# Adventure Land — Godot 4 Prototype

Minimal 2-scene prototype: player movement, NPC interaction, dialogue box.

## Prerequisites
- Godot 4.6.2 .NET edition (macOS universal)
- .NET 8 SDK

## Setup Instructions

### 1. Copy this project to your Mac

Copy the entire `AdventureLandPrototype/` folder to wherever you keep projects.

### 2. Drop in your asset files

The project references these files. Copy them from your Google Drive Tiled folder:

```
assets/
├── tilesets/
│   ├── FantasyForest_Combo.png    ← from Tiled/Assets/
│   └── Light_Grass_BG.png         ← from Tiled/Assets/
├── buildings/
│   ├── Blacksmith.png             ← from Tiled/Assets/Structure Sprites/
│   ├── Cabin1.png
│   ├── Cabin2.png
│   ├── Shop.png
│   ├── Weapon Shop.png
│   ├── Windmill.png
│   ├── Well.png
│   └── AL_TreeSign.png
└── sprites/
    ├── player/
    │   └── fbas_01body_human_00a.png   ← your Mana Seed base body sheet (1024x1024)
    └── npc/
        └── penny.png                   ← Penny's spritesheet (128x256)
```

### 3. Open in Godot

1. Launch Godot 4.6.2 .NET
2. Click "Import" → navigate to the project folder → select `project.godot`
3. Click "Import & Edit"
4. Godot will import all assets and generate `.import` files automatically

### 4. Build the C# solution

In the Godot editor:
1. Go to **Project → Tools → C# → Create C# Solution** (if prompted)
2. Or click **Build** (hammer icon) in the top-right toolbar
3. Wait for the build to succeed — check the Output panel for errors

### 5. Run!

Press **F5** (or the play button). You should see:
- The village map with grass background and tile layers
- Buildings placed at their Tiled positions
- Your player character in the center (WASD/arrows to move)
- Penny the NPC — walk up to her and press **E** to talk
- Dialogue box appears, press **E** or **Space** to advance, closes after last line

## Controls

| Key | Action |
|-----|--------|
| WASD / Arrow keys | Move (8 directions) |
| E / Enter | Interact with NPC / Advance dialogue |
| Space | Advance dialogue |

## Tuning Animation Frames

The player uses the **Mana Seed cell-based system** (64x64 cells, 16 columns).
Animation cell IDs are defined in `scripts/player/ManaSeedAnimator.cs`.

To fix walk animations:
1. Open your Mana Seed animation guide image
2. Find the WALK section — note the cell IDs for each direction
3. Update the `Animations` dictionary in `ManaSeedAnimator.cs`
4. Rebuild (Ctrl+Shift+B in Godot)

The NPC frame size is set to 32x48 in `scripts/npc/NpcAnimator.cs`.
If Penny looks cropped or offset, adjust `FrameWidth` and `FrameHeight`.
